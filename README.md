# Пастель

Блокнот и раскраска по номерам для Apple Pencil на iPad. Веб-приложение: открывается в Safari, ставится на экран «Домой», работает офлайн. Без рекламы, без сторонних библиотек и без сборки.

## Запустить на компьютере

```bash
python3 -m http.server 8790 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8790/. Мышь рисует. Ctrl или Cmd с колесом масштабирует, колесо сдвигает страницу.

## Поставить на iPad

1. Открыть адрес приложения в Safari. Для офлайна нужен https: например, GitHub Pages.
2. «Поделиться» → «На экран „Домой“».
3. Открывать с иконки. Так Safari бережнее хранит данные.

## Устройство

| Файл | Что делает |
|---|---|
| `js/app.js` | главный экран, блокноты, резервная копия, переходы |
| `js/notebook.js` | экран блокнота: карандаш, пальцы, страницы, отмена, сохранение, экспорт |
| `js/ink.js` | как рисуются ручка, карандаш, маркер, ластик, бумага и шаблоны страниц |
| `js/db.js` | хранилище IndexedDB |
| `js/ui.js`, `js/icons.js`, `js/covers.js` | меню и диалоги, иконки, обложки |
| `js/shapes.js` | распознавание фигур по удержанию карандаша |
| `js/stickers.js` | стикеры: рисунки, метки с текстом, текст с выбором шрифта, фото |
| `js/coloring.js` | экран раскраски: акварель и заливка в границах номера, 90 %, подсказка, прогресс |
| `js/pbn.js` | сборщик раскраски из картинки (области, номера, места для цифр); им же собирается «Своя картинка» на iPad |
| `data/` | готовые раскраски: `catalog.json`, карты областей `.bin`, палитры `.json`, миниатюры |
| `pictures/code/` | исходники картинок, нарисованных кодом |
| `tools/` | сборка библиотеки: `node tools/build-library.cjs <список.json>` (нужен Playwright) |
| `css/app.css` | оформление, все цвета в начале файла |
| `sw.js` | офлайн-кэш. **После любых правок поднять `VERSION`**, иначе iPad покажет старую версию |

Шрифты лежат в `fonts/`, все под SIL Open Font License 1.1:
- Comfortaa и Nunito — для интерфейса;
- Caveat, Bad Script, Pangolin, Cormorant Garamond, Pacifico и Yeseva One — для текста в блокноте.

План, решения и рекомендации — в `docs/plan.md`.
